About The Technologies Used

An overview of the full-stack technology stack, machine learning libraries, and system architecture.

Machine Learning Project

Heart Disease Prediction System

This application is a full-stack Machine Learning web project engineered to evaluate cardiovascular risk factors from 13 clinical biomarkers. Powered by a Decision Tree Classifier (`DecisionTreeClassifier`), it delivers real-time risk predictions, interactive Chart.js analytics, and automated PDF report downloads.

Technologies & Libraries Used

A detailed breakdown of all software technologies powering this application.

Python 3.14
Core Language

Powers data ingestion, machine learning pipeline execution, and web server logic.

Flask 3.0
Web Framework

Micro-framework serving RESTful routes, Jinja2 dynamic templates, and session states.

Scikit-Learn
ML Engine

Implements `DecisionTreeClassifier`, Gini splits, and 80/20 stratified validation.

Pandas & NumPy
Data Processing

Used for dataset manipulation (`heart.csv`), array operations, and statistics.

Chart.js
Interactive Charts

Renders dynamic client-side Doughnut and Bar charts on the Analytics Dashboard.

ReportLab PDF
PDF Document Engine

Compiles downloadable patient medical reports with diagnostic tables and care plans.

Bootstrap 5 & CSS3
Responsive UI

Provides modern responsive glassmorphism card layouts and high-contrast typography.

Joblib & CSV
Model Storage

Serializes `heart_model.pkl` binary and maintains persistent prediction history logs.

Educational & Portfolio Disclaimer

This system is engineered exclusively for educational, scientific research, and developer portfolio demonstration purposes.
